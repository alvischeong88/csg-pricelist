Unit Availability Board — Sample

Setia Alam Heights, Block A

Click an available unit to lock it in for a buyer.

This board talks directly to Supabase — bookings and status changes persist and are shared across everyone using it. Before this works, set SUPABASE_URL and SUPABASE_ANON_KEY near the top of the script to match your Supabase project (see the deployment guide). Admin login uses the account you create under Supabase's Authentication → Users, so the check happens on Supabase's side, not in this page's code.
